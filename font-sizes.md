## สรุปภาพรวม

| ระดับ      | px      | ใช้กับ                                     |
| ---------- | ------- | ------------------------------------------ |
| Micro      | 10px    | badge เล็ก ("Hot", "Most Popular")         |
| Caption    | 12px    | badge labels, secondary labels, copyright  |
| Body Small | 14px    | nav links, card content, feature list      |
| Body       | 16px    | subtext, card titles, step labels          |
| Body Large | 18px    | subtext responsive, step numbers, price    |
| Subheading | 24px    | logo (Navbar + Footer), stats, featured H3 |
| Heading SM | 30–36px | section H2 mobile                          |
| Heading MD | 36–48px | section H2 tablet                          |
| Heading LG | 48–72px | Hero H1, section H2 desktop                |
